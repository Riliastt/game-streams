# Консоль Яндекс Игр — чеклист (делаете вы)

Это шаги вне кода. Без них игру нельзя опубликовать и получать выплаты.

## 1. Аккаунт

1. Войдите с [Яндекс ID](https://passport.yandex.ru/).
2. Откройте [Консоль разработчика](https://games.yandex.ru/console).
3. Примите условия для разработчиков.

## 2. Черновик игры

1. Создайте новую игру.
2. Название (рабочее): например «Game Streams» / «Стрим-студия».
3. Устройства: **Desktop + Mobile**.
4. Категория: симуляторы / кликеры (уточните по списку в консоли).
5. Включите опцию **«Игра использует облачные сохранения»**.
6. Подключите монетизацию (реклама) в настройках черновика.

## 3. Юридический статус для выплат

Оформите один из вариантов и укажите реквизиты в консоли:

- самозанятый;
- ИП;
- юридическое лицо.

Без этого доход с рекламы/покупок не вывести.

## 4. Промоматериалы (перед модерацией)

- иконка игры;
- обложка;
- скриншоты (мобильные и десктоп);
- описание на русском.

## 5. Загрузка билда

1. Локально: `npm run build` → архив из папки `dist` (`npm run zip`).
2. В корне ZIP должен быть `index.html`.
3. Размер распакованного билда &lt; 100 МБ.
4. Загрузите ZIP в черновик → проверьте в песочнице → отправьте на модерацию.

Модерация обычно 3–5 рабочих дней. Документация: https://yandex.ru/dev/games/doc/ru/
