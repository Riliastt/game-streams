# Game Streams

Гибридная HTML5-игра для **Яндекс Игр**: кликер-стрим + менеджмент студии + нарратив.

## Стек

Vite + React + TypeScript + SDK Яндекс Игр (с mock для локальной разработки).

## Быстрый старт

```bash
npm install
npm run dev
```

Откройте локальный URL из терминала. Mock SDK в `public/sdk.js` эмулирует сохранения и рекламу.

## Сборка для Яндекс Игр

```bash
npm run zip
```

Получите `game-streams-yandex.zip` — в корне архива лежит `index.html`. Загрузите ZIP в [Консоль](https://games.yandex.ru/console).

Чеклист аккаунта и модерации: [CONSOLE_SETUP.md](./CONSOLE_SETUP.md).

## Игровой цикл

1. **Стрим** — кликер, живой чат, алерты, комбо, события (рейд, техсбой, спонсор, модер).
2. **Студия** — апгрейды, визуал комнаты, темы, имя канала, энергия/выгорание.
3. **Команда** — найм, проекты (клипы/shorts), ранги канала.
4. **Цели** — дневные квесты и достижения.
5. **Сюжет** — арка 1 + арка 2 (Луч, Марина, Volt, Nexus) и несколько концовок.

## Монетизация MVP

- полноэкранная реклама при сборе награды (раз в ~90 сек);
- rewarded: x2 награда за стрим, +2 энергии.
